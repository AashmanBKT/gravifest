# GraviFest – Event Management Platform

## Overview

GraviFest is a full-stack event management platform designed to streamline the planning, registration, administration, and monitoring of large-scale technical and cultural events.

The platform enables organizers to manage participants, events, registrations, schedules, and analytics through a centralized dashboard.

---

## Features

### Participant Management
- User Registration & Login
- Profile Management
- Event Enrollment
- Registration Tracking

### Event Management
- Create & Manage Events
- Event Scheduling
- Capacity Management
- Category-wise Event Organization

### Admin Dashboard
- Participant Analytics
- Registration Statistics
- Event Performance Monitoring
- Real-time Activity Tracking

### Security
- JWT Authentication
- Role-Based Access Control
- Protected Routes
- Secure API Access
